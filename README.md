# 💻 Interactive Terminal Portfolio

Welcome to my interactive, command-line interface (CLI) styled portfolio. This project simulates a floating macOS terminal window right in your browser, allowing users to execute commands to learn more about my skills, projects, and background.

**🟢 Live Demo:** [View Live Portfolio](https://ruscodes.github.io/terminal-portfolio/)

## 🚀 Features
* **Interactive CLI:** Type commands like `/about`, `/skills`, and `/projects` to navigate the portfolio.
* **Command History:** Use the `Arrow Up` and `Arrow Down` keys to cycle through previously entered commands.
* **Auto-completion:** Press `Tab` to auto-complete commands or view suggestions.
* **Theme Toggling:** Switch between the default macOS aesthetic and a Matrix-inspired hacker theme (`/theme hacker`).
* **Hidden Easter Eggs:** Try finding the classified directory or running `/deployopspilot` to see simulated DevOps pipelines.
* **Responsive Design:** Fully optimized for mobile screens, retaining the authentic "windowed" terminal feel without breaking the layout.

## 🛠️ Tech Stack
This project was built from scratch without relying on heavy JavaScript frameworks:
* **HTML5:** Semantic structure and boot-sequence rendering.
* **CSS3:** Custom animations, responsive scaling, and UI styling.
* **JavaScript (Vanilla):** DOM manipulation, event listeners, canvas rendering (for the Matrix effect), and command routing.
* **Bootstrap 5.3:** Utilized strictly for base grid layout management.
